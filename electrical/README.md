# 電装設計

## ファイル配置

| 置き場所 | 入れるもの |
|---|---|
| `pcb/<基板名>/` | KiCad プロジェクト一式 (回路図・PCB・プロジェクトファイル) |
| `pcb/lib/` | 共通シンボル・フットプリント・3Dモデル |
| `schematics/` | 回路図 PDF (レビュー用エクスポート) |
| `fab/<基板名>/rev<N>/` | ガーバー・ドリル・Pick&Place (製造データ) |
| `wiring/` | ハーネス図・結線表・コネクタピンアサイン |
| `datasheets/` | 採用部品のデータシート |
| `bom/` | 電子部品表 CSV |

## ルール

- KiCad ソースは **LFS に入れない**。テキストなので差分レビューできる状態を保つ。
- `fab/` はリビジョンごとのディレクトリに保存し、**上書きしない**。
  製造した実基板と一対一で追跡するため。
- ピンアサインは `wiring/pinout.md` を正本とし、
  `firmware/common/include/pinmap.h` と一致させる。
