# 運動学 (Kinematics)

## 座標系定義

- ベース座標系 `{0}`: 設置面、J1 回転軸を Z 軸、正面を X 軸
- 手先座標系 `{T}`: 前腕先端の取付面中心

> TBD: 座標系の図を `docs/images/frames.png` に置く。

## DH パラメータ

| i | θi | di | ai | αi |
|---|---|---|---|---|
| 1 | θ1 | L0 | 0  | 90° |
| 2 | θ2 | 0  | L1 | 0   |
| 3 | θ3 | 0  | L2 | 0   |

> 上表は一般的な3軸垂直多関節の形。実機構が決まり次第検証すること。

## 順運動学 (FK)

関節角 (θ1, θ2, θ3) → 手先位置 (x, y, z)。3自由度なので姿勢は決まらず、
位置のみが制御対象になる。実装: `software/robot_core/vmjr/kinematics/`

## 逆運動学 (IK)

位置 (x, y, z) → 関節角。3軸の場合は**解析解**が得られる。

- θ1 は atan2(y, x) で一意 (旋回)
- θ2, θ3 は 2リンク平面問題 → **肘上 / 肘下の2解**が存在

解の選択方針 (現在姿勢に近い方を選ぶ / 肘上に固定する など) を決めて
`docs/adr/` に記録する。

## 特異点

- 原点直上 (x=y=0): θ1 が不定
- 腕の伸び切り (到達限界): ヤコビアンがランク落ち

これらの近傍での挙動を `simulation/notebooks/` で確認し、
`config/joint_limits.yaml` のソフトリミットで回避する。
