# 設計計算書 — 可搬質量・速度性能の試算

対象: 3軸垂直多関節ロボット VMJR
構成部品: **CubeMars AK80-64 KV80 ×2** + **RobStride EduLite 05 ×1**

本書の数値はすべて `tools/calc_payload.py` の出力。前提を変えたら再実行して更新すること。

```bash
python3 tools/calc_payload.py
```

## 0. 結論 (先に要点)

| 問い | 答え |
|---|---|
| 何キロ持てるか | **リーチ450mmでは約0.1 kg。前腕を120mmに詰めて約0.6 kg** |
| 何が効いているか | **EduLite 05 の定格1.8 N·m が唯一の制約**。AK80-64 は使用率3〜13%で過剰 |

## 2. モデル化

### 2.1 軸構成と記号

```
        TCP (m_tool + m_p)
         ●
         │ L2  (前腕 m_link2)
    J3 ──○
         │ L1  (上腕 m_link1)
    J2 ──○
         │
    J1 ──╋  ← 鉛直軸まわりの旋回
        ▓▓▓ ベース
```

| 記号 | 意味 | 基準値 |
|---|---|---|
| `L1` | J2 → J3 距離 (上腕) | 250 mm |
| `L2` | J3 → TCP 距離 (前腕 + ツールオフセット) | 200 mm |
| `R` | リーチ = L1 + L2 | 450 mm |
| `m_link1` | 上腕の構造質量 (重心 L1/2) | 0.35 kg |
| `m_link2` | 前腕の構造質量 (重心 L2/2) | 0.25 kg |
| `m_j3` | J3 アクチュエータ質量 (J3 位置に集中) | 構成による |
| `m_tool` | エンドエフェクタ質量 (TCP 位置) | 0.30 kg |
| `m_p` | ペイロード (TCP 位置) | 求めたい値 |
| `g` | 重力加速度 | 9.81 m/s² |

> リンク質量は仮値。CAD 確定後に実測値へ置き換えること。

### 2.2 評価姿勢

**腕を水平に全伸展した姿勢** (J2 = 0°, J3 = 0°) を最悪条件とする。
この姿勢で重力モーメントの腕の長さが最大になる。

### 2.3 安全率と設計角加速度

- 安全率 `SF = 1.5` — 連続定格トルクに対して適用
- 設計角加速度 `α = 10 rad/s²` — 全軸共通

角加速度は「駆動できるか」ではなく「構造が耐えるか・振動しないか」で決まる。
10 rad/s² は 3Dプリント/薄肉アルミ構造の教育用アームとして穏当な値。
CAD とたわみ計算が出たら見直すこと。

## 3. 計算式の導出

### 3.1 静トルク (重力)

水平伸展時、関節 `j` まわりの重力トルクは各質量の「質量 × 水平距離」の総和:

```
τ_gravity = g × Σ (m_i × r_i)
```

**J3 (手先側の関節) まわり** — J3 より先にあるのは前腕・ツール・ペイロード:

```
τ3_gravity = g × [ m_link2 × (L2/2) + (m_tool + m_p) × L2 ]
```

**J2 (肩) まわり** — J3 アクチュエータ自身も荷重になる:

```
τ2_gravity = g × [ m_link1 × (L1/2)
                 + m_j3    × L1
                 + m_link2 × (L1 + L2/2)
                 + (m_tool + m_p) × (L1 + L2) ]
```

**J1 (旋回)** — 回転軸が鉛直なので**重力トルクはゼロ**。慣性と摩擦だけ。
ただし出力軸には大きな**曲げモーメント**がかかる (§7 参照)。

### 3.2 慣性モーメント

一様な棒が端まわりに回る場合 `I = mL²/3`、点質量は `I = mr²`。

```
I3 = m_link2 × L2²/3 + (m_tool + m_p) × L2²
I2 = m_link1 × L1²/3
   + m_j3    × L1²
   + m_link2 × (L1² + L1·L2 + L2²/3)     ← 平行軸の定理
   + (m_tool + m_p) × R²
```

前腕の項は、重心が `L1 + L2/2` にある長さ `L2` の棒なので

```
I = I_cm + m·d² = m·L2²/12 + m·(L1 + L2/2)²
  = m·(L1² + L1·L2 + L2²/4) + m·L2²/12
  = m·(L1² + L1·L2 + L2²/3)
```

J1 (鉛直軸) は水平伸展時の半径が J2 と同じなので `I1 ≈ I2` とする。

### 3.3 可搬質量の逆算

必要トルクが許容トルク以下という条件:

```
g × (Σm_i·r_i + m_p·r) + α × (ΣI_i + m_p·r²) ≤ τ_rated / SF
```

`m_p` について解くと (重力項・慣性項とも `m_p` に対して線形):

```
              τ_rated/SF − g·Σm_i·r_i − α·ΣI_i
   m_p ≤  ──────────────────────────────────────
                    g·r + α·r²
```

分母の `g·r` が重力分、`α·r²` が加速分。**リーチ `r` が長いと分母が2乗で効く**
ので、可搬質量はリーチに対して急速に落ちる。

## 4. 案A: J1=AK80-64 / J2=AK80-64 / J3=EduLite 05

手先側に軽い EduLite を置く、最も自然な配置。

### 4.1 J3 (EduLite 05) の計算過程

```
Σm·r = m_link2×(L2/2) + m_tool×L2
     = 0.25 × 0.100 + 0.30 × 0.200
     = 0.0250 + 0.0600 = 0.0850 kg·m

τ3_gravity = 9.81 × 0.0850 = 0.834 N·m     ← ペイロード0でこれ

I3 = 0.25 × 0.20²/3 + 0.30 × 0.20²
   = 0.003333 + 0.012000 = 0.015333 kg·m²

τ_allow = 1.8 / 1.5 = 1.200 N·m

          1.200 − 0.834 − 10 × 0.015333       1.200 − 0.834 − 0.153
m_p ≤ ──────────────────────────────────  =  ─────────────────────
           9.81 × 0.20 + 10 × 0.20²              1.962 + 0.400

      = 0.2127 / 2.362 = 0.090 kg
```

**ペイロード 0 の時点で定格の46%を重力保持に使っている**のが効いている。
前腕とツールの自重だけで 0.834 N·m、許容 1.200 N·m の残りは 0.366 N·m しかない。

### 4.2 J2 (AK80-64) の計算過程

```
Σm·r = 0.35×0.125 + 0.242×0.250 + 0.25×0.350 + 0.30×0.450
     = 0.04375 + 0.06050 + 0.08750 + 0.13500 = 0.32675 kg·m

τ2_gravity = 9.81 × 0.32675 = 3.205 N·m

I2 = 0.35×0.25²/3 + 0.242×0.25² + 0.25×(0.25² + 0.25×0.20 + 0.20²/3) + 0.30×0.45²
   = 0.007292 + 0.015125 + 0.031458 + 0.060750 = 0.114625 kg·m²

τ_allow = 48 / 1.5 = 32.0 N·m

          32.0 − 3.205 − 10 × 0.114625        27.649
m_p ≤ ────────────────────────────────  =  ──────── = 4.29 kg
          9.81 × 0.45 + 10 × 0.45²            6.440
```

### 4.3 案A の結果

| 軸 | アクチュエータ | 許容トルク | 最大ペイロード |
| --- | --- | ---: | ---: |
| J3 | EduLite 05 | 1.20 N·m | **0.09 kg** |
| J2 | AK80-64 (48V) | 32.00 N·m | 4.29 kg |

**可搬質量 = 0.09 kg** (制約軸: J3)

このとき J2 の所要トルクは 4.93 N·m、**定格48 N·m に対して 10.3%**。
肩の AK80-64 は能力の 9割を使わないまま終わる。

## 5. 案B: J1=EduLite 05 / J2=AK80-64 / J3=AK80-64

「重力トルクがかからない J1 に小さいアクチュエータを置けばいい」という発想。
J3 が AK80-64 (0.85 kg) になるので肩の負担は増えるが、48 N·m あるので余裕。

| 軸 | アクチュエータ | 許容トルク | 最大ペイロード |
| --- | --- | ---: | ---: |
| J3 | AK80-64 (48V) | 32.00 N·m | 13.13 kg |
| J2 | AK80-64 (48V) | 32.00 N·m | 4.00 kg |
| J1 | EduLite 05 (重力0/慣性のみ) | 1.20 N·m | **−0.05 kg** |

**可搬質量 = 成立しない** (制約軸: J1)

J1 は重力トルクこそゼロだが、**アーム全体の慣性 0.115 kg·m² を
α = 10 rad/s² で加速するのに 1.15 N·m** 必要で、許容 1.20 N·m をほぼ使い切る。
ペイロードを載せる余地がない。

角加速度を落とせば成立はする:

| α_J1 [rad/s²] | 許容ペイロード [kg] |
| ---: | ---: |
| 2 | 0.19 |
| 5 | 0.08 |
| 10 | −0.05 |
| 20 | −0.22 |

**さらに致命的な問題**: J1 は鉛直軸なので、アームの自重が出力軸に
**曲げモーメント**として丸ごとかかる。ペイロード2 kg 時で **13.5 N·m**。
242 g のアクチュエータの出力軸受がこれを支えられるとは考えにくく、
別途クロスローラベアリング等で荷重を逃がす機構が必須になる。

→ **案B は非推奨。** J1 に EduLite を使うなら、旋回テーブル用の軸受を
別に設けた上で、低加速度運用に限定すること。

### 6.1 前腕長 L2 の影響 (案A)

`τ3 ∝ L2` なので、**前腕を半分にすれば可搬質量はほぼ倍以上になる**。

| ---: | ---: | ---: | ---: |
| 100 | 0.15 | 0.270 | **0.84** |
| 100 | 0.30 | 0.417 | 0.69 |
| 150 | 0.15 | 0.405 | 0.44 |
| 150 | 0.30 | 0.625 | 0.29 |
| 200 | 0.15 | 0.540 | 0.24 |
| 200 | 0.30 | 0.834 | 0.09 |
| 250 | 0.15 | 0.674 | 0.12 |
| 250 | 0.30 | 1.042 | **0.00** |
| 300 | 0.15 | 0.809 | 0.05 |
| 300 | 0.30 | 1.251 | **0.00** |

L2 = 250 mm でツール 0.30 kg だと、**自重だけで定格を超える** (1.042 N·m > ...)
ので、そもそもペイロードなしでも姿勢を保持できない。

### 6.2 目標ペイロードから逆算した許容前腕長

| 目標ペイロード [kg] | ツール0.15kg: 許容L2 [mm] | ツール0.30kg: 許容L2 [mm] |
| ---: | ---: | ---: |
| 0.25 | 197 | 157 |
| 0.50 | 139 | 119 |
| 0.75 | 108 | 95 |
| 1.00 | 88 | 80 |
| 1.50 | 65 | 60 |

**1 kg を持ちたいなら前腕は 80〜90 mm** しか取れない。
これは事実上「手首直結」で、多関節アームとして成立しにくい。

### 6.3 安全率の影響 (L2=200mm / ツール0.30kg)

| 安全率 SF | 許容トルク [N·m] | 可搬質量 [kg] |
| ---: | ---: | ---: |
| 1.0 | 1.80 | 0.34 |
| 1.2 | 1.50 | 0.22 |
| 1.5 | 1.20 | 0.09 |
| 2.0 | 0.90 | 0.00 |

安全率の取り方だけで 0〜0.34 kg と 3倍以上ぶれる。
**カタログの「可搬質量」を比べるときは安全率の定義を確認すること。**

### 6.4 ピークトルク基準 (瞬時)

| 基準トルク | 許容トルク(SF=1.5) | ペイロード [kg] |
| ---: | ---: | ---: |
| 定格 1.8 N·m | 1.20 N·m | 0.09 |
| ピーク 6.0 N·m | 4.00 N·m | 1.28 |

ピーク基準なら 1.28 kg だが、**これは連続保持できない**。
QDD アクチュエータは定格を超えると急速に発熱するため、
「持ち上げた姿勢で待機する」用途にはピーク値を使ってはいけない。
加減速のピークにのみ使うこと。

## 8. 速度性能

### 8.1 関節速度 → 手先速度

```
ω [rad/s] = 2π × N[rpm] / 60
v_tcp [m/s] = ω × R
```

AK80-64 @48V: `ω = 2π × 48 / 60 = 5.03 rad/s`

| アクチュエータ | 定格回転数 | 角速度 [rad/s] | R=450mm での手先速度 [m/s] |
| --- | ---: | ---: | ---: |
| AK80-64 (24V) | 23 rpm | 2.41 | 1.08 |
| AK80-64 (48V) | 48 rpm | 5.03 | **2.26** |
| EduLite 05 | 100 rpm | 10.47 | 4.71 |

**24V と 48V で手先速度が 2倍違う。48V 駆動を強く推奨。**

EduLite の 4.71 m/s は見かけ上速いが、J3 は手先の姿勢を変えるだけで
TCP を大きく動かす軸ではないので、実際のサイクルタイムは J1/J2 で決まる。

### 8.2 90° 移動の所要時間 (台形速度プロファイル)

加速・減速で進む角度 `θ_acc = ω_max²/α`。
これが移動角 `θ` 以上なら最高速に届かない三角プロファイル:

```
θ_acc ≥ θ  →  t = 2√(θ/α)          (三角)
θ_acc < θ  →  t = 2ω_max/α + (θ − θ_acc)/ω_max   (台形)
```

| 軸 / アクチュエータ | α [rad/s²] | ω_max [rad/s] | 時間 [s] | プロファイル |
| --- | ---: | ---: | ---: | --- |
| J2 AK80-64 @24V | 10 | 2.41 | 0.89 | 台形 |
| J2 AK80-64 @24V | 20 | 2.41 | 0.77 | 台形 |
| J2 AK80-64 @48V | 10 | 5.03 | 0.79 | 三角 |
| J2 AK80-64 @48V | 20 | 5.03 | **0.56** | 台形 |
| J3 EduLite 05 | 10 | 10.47 | 0.79 | 三角 |
| J3 EduLite 05 | 20 | 10.47 | 0.56 | 三角 |

**重要**: 48V + α=10 のケースは三角プロファイル、つまり
**最高速度に到達する前に減速に入っている**。90°程度の短い移動では
最高回転数より**角加速度のほうが支配的**で、
モータを速くするより構造を軽く・硬くするほうがサイクルタイムに効く。

### 8.3 サイクルタイムの目安

ピック&プレース1サイクルを「J1旋回90° → J2/J3で降下・上昇 ×2」と仮定すると、
48V・α=20 で **概ね 2〜3 秒/サイクル**。
実際には停止後の整定時間 (振動収束) が加わるため、構造剛性次第で悪化する。

## 9. 位置決め精度

### 9.1 バックラッシ

AK80-64 のバックラッシ 10 arcmin を rad に直すと:

```
10 arcmin = (10/60)° = 0.1667° = 0.1667 × π/180 = 2.909 mrad
```

手先位置への影響 (R = 450 mm):

| 軸 | 腕の長さ [mm] | 手先誤差 [mm] |
| --- | ---: | ---: |
| J1 (旋回) | 450 | 1.31 |
| J2 (肩) | 450 | 1.31 |

- J1 + J2 の単純和 (最悪) = **2.62 mm**
- RSS (二乗和平方根) = 1.85 mm

**バックラッシが正確度の支配項**。0.1 mm オーダーの精度が要るなら
この構成では届かない。繰返し精度は同方向から近づけば改善するので、
**片方向アプローチ** (常に同じ向きから目標に入る) を軌道生成側で実装すること。

> EduLite 05 のバックラッシは未公開。9:1 の遊星減速機なので
> 10〜30 arcmin 程度と推測されるが、**要実測**。

### 9.2 たわみ (未計算)

構造のたわみはバックラッシと同等以上に効く可能性がある。
CAD 確定後、以下を `mechanical/fea/` で確認すること:

- 全伸展・最大ペイロード時の TCP たわみ量
- 1次固有振動数 (整定時間を決める。目標 30 Hz 以上)

| AK80-64 定格出力 | 220 W ×2 = 440 W | カタログ値 |
| EduLite 05 定格出力 | 約 19 W | 定格トルク × 定格角速度 |
| 合計 (定格) | 約 459 W | 単純和 |
| 48V 系の定格電流 | 約 9.6 A | P/V |
| **推奨電源** | **48 V / 600 W 以上** | 定格の約1.3倍 + 突入余裕 |

- 全軸が同時に定格を出すことは稀なので 459 W は保守的な値。
  ただし**電流制限にかかると軌道が崩れる**ので、ピークに耐える電源を選ぶこと。
- 減速時の**回生**で母線電圧が上昇する。48V 電源なら回生吸収回路
  (ブレーキチョッパ or 大容量コンデンサ) の検討が必要。
- EduLite 05 は 15–60 V 対応なので 48 V 系に統一できる。

### 発熱

損失は概ねトルクの2乗に比例する (`P_loss ∝ τ²`)。

- J2 (AK80-64, 使用率 12.7%) → 定格時損失の約 1.6%。放熱設計不要。
- J3 (EduLite 05, 使用率 66.7%) → 定格時損失の約 44%。**連続運転時は要注意**。
  姿勢保持が長い用途なら、機械的なブレーキで保持してモータを無励磁にすること。

## 11. まとめと推奨

### 数値まとめ

| 構成 | リーチ | 可搬質量 | 制約軸 | 手先速度(48V) |
|---|---:|---:|---|---:|
| 案A (L2=200) | 450 mm | 0.09 kg | J3 EduLite | 2.26 m/s |
| 案B (J1=EduLite) | 450 mm | 成立せず | J1 EduLite | — |
| **案C (推奨)** | **370 mm** | **0.62 kg** | J3 EduLite | 1.86 m/s |

### 推奨事項

1. **軸配置は案A (J1/J2 = AK80-64, J3 = EduLite 05)** とする。
   案Bは J1 の曲げモーメント 13.5 N·m が現実的でない。
2. **前腕 L2 を 120 mm 程度に詰める**。これだけで可搬質量が 0.09 → 0.62 kg になる。
3. **エンドエフェクタは 0.2 kg 以下**に抑える。ツール質量はペイロードと等価に効く。
4. **48 V 駆動**とする。24V だと手先速度が半減する。
5. **サイクルタイムは角加速度で決まる**ので、構造の軽量化・高剛性化を優先する。
   モータの最高回転数は 90° 移動では使い切れない。

### 構成の見直しを検討するなら

AK80-64 (48 N·m) と EduLite 05 (1.8 N·m) の**27倍のトルク差**が根本問題。
同クラスで揃えたほうが素直な設計になる:

| 見直し案 | 内容 | 期待効果 |
|---|---|---|
| J3 を中間クラスに | J3 を 5〜10 N·m 級 (AK70-10, RobStride 03 等) に | 可搬質量 1〜2 kg、リーチ 450mm を維持 |
| AK80-64 を J2/J3 に | J1 に別途減速機+小型モータ+旋回軸受 | 可搬質量 2〜3 kg (構造が制約になる) |
| 現構成のまま小型化 | 案C (リーチ 370 mm) | 追加購入なしで 0.6 kg |
