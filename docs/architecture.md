# システム構成 (Architecture)

## 全体ブロック

```
[ 上位PC ]                     [ 制御盤 ]                  [ 機体 ]
 ROS 2 / GUI                メイン制御基板              J1/J2/J3
 ├ 動作計画                  ├ MCU                       ├ モータ
 ├ 逆運動学     ── USB/CAN ─ ├ 通信 I/F      ── 動力線 ─ ├ エンコーダ
 └ 軌道生成                  ├ モータドライバ×3           └ 原点センサ
                             └ 非常停止回路
```

> TBD: 確定後にブロック図を `docs/images/` に置いて差し替える。

## 責務分担

| 層 | 担当 | 周期 |
|---|---|---|
| 上位PC | 動作計画、逆運動学、軌道生成、教示 | 10〜100 Hz |
| MCU | 位置/速度/電流ループ、原点復帰、リミット監視 | 1〜10 kHz |
| ハード | 非常停止 (ソフトを介さず遮断) | — |

**原則**: 安全に関わる遮断はソフトウェアに依存させない。

## 通信仕様

- 物理層: TBD (CAN / RS-485 / USB-CDC)
- プロトコル定義: `firmware/common/include/protocol.h` (上位ソフトと共有)
- 上位側実装: `software/robot_core/vmjr/comm/`

プロトコルを変更したら**両側のバージョンを同時に上げる**こと。
