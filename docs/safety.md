# 安全設計 (Safety)

## 基本方針

1. **非常停止はハードウェアで成立させる** — 押下でモータ電源を物理遮断する。
   MCU や上位ソフトの正常動作を前提にしない。
2. **リミットは三重化** — メカストッパ (機械) / リミットスイッチ (電気) /
   ソフトリミット (`config/joint_limits.yaml`)。
3. **電源投入直後は動かさない** — 原点復帰が完了するまで指令を受け付けない。

## チェックリスト (通電前に毎回)

- [ ] 非常停止ボタンが押下位置で電源を遮断することを確認
- [ ] 各軸のリミットスイッチが反応することを確認
- [ ] 可動範囲内に人・工具が無いことを確認
- [ ] `config/joint_limits.yaml` の値が機構の限界内であること

## リスクアセスメント

| 危険源 | 想定被害 | 対策 |
|---|---|---|
| 挟まれ | 手指の負傷 | 可動範囲の柵、非常停止 |
| 落下 | 手先ワークの落下 | 電源断時のブレーキ / 保持トルク |
| 暴走 | 想定外の高速動作 | ソフトリミット + 速度上限、電流監視 |
| 発熱 | モータ・ドライバ焼損 | 温度監視、デューティ制限 |
